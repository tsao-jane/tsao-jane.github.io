How I use AI

If I can’t trace it, it doesn’t ship.

  1. I set the rulesRequired fields, approved sources, what counts as an exception.e.g. the columns a product import must fill
  2. AI does the repetitive partCollecting, structuring, drafting, formatting.e.g. gathering specs across five vendor lines
  3. I review before it shipsSpot-checks against the source; exceptions handled by hand.
  4. The method gets savedSo the next run starts where this one ended.e.g. packaged as a reusable Claude Skill

The AI drafts and gathers. I decide what is required, what counts as an exception, and what goes live.
